# Labrador Background Artwork

`labrador-monogram-v1.png` is the generated master; `labrador-monogram-v1.webp` is the optimized copy. Initially saved for review only, the optimized pattern is now imported by the approved 2026-10-15 storefront integration at a subtle opacity. Its visibility is controlled by Website UI presentation settings.

Generated with the built-in image tool on 2026-10-13. Prompt: preserve an original diagonal repeat of small front/profile Labrador heads and paws; use oat, cacao, kraft, blue and yellow from the existing brand palette; no designer letters/logos, text or watermark. The pattern is intended for repeating backgrounds, but exact seamless edge continuity has not been certified. Raster shades are illustrative, not exact CSS color tokens.

The website's six main colors remain Blue `#2F57B7`, Yellow `#F2DE5C`, Kraft `#CDAA7E`, Cacao `#6A3C2B`, Oat `#F3E8D2`, and Campaign Emerald `#17634C` with giving surface `#EDF6F0`. Emerald is reserved for giving contexts, not this pattern.

`labrador-pair-template.webp` and `labrador-portrait-template.webp` in this folder are illustrative templates. They do not represent real portraits of Chase/Evie or customer reviews. The pair reuses the previously generated wide garden image; the added portrait uses an eye-level chocolate Labrador in a sunlit garden, no text/logos. Real approved photography remains a later content task.

`sample-product-packshots.webp` is an eight-image contact sheet of generated treat-packaging concepts. Product names, prices and giving eligibility in the accompanying design preview are fictional fixtures, not database records or approved packaging.

The three newer Labrador templates, the full image placement map and replacement guidance are documented in [image-placement-guide.md](image-placement-guide.md). Their approved application integration uses `brandContent.js` for Home/Brand/fictional Campaign imagery. These are still illustrative templates, not actual brand/partner portraits. Final deployment results are recorded in the handoff.
